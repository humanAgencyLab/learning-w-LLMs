# SRL System Research Study Design

## Study Overview
- **Participants**: 200 users from Prolific
- **Duration**: 1-2 hours per participant
- **Goal**: Measure SRL effectiveness
- **Token Budget**: 50,000 tokens/day (Groq free tier)

## Study Phases

### Phase 1: Pre-Assessment (5-10 minutes)
- Demographics and learning background
- SRL self-assessment questionnaire
- Topic selection (Python, Guitar, or Piano)

### Phase 2: Learning Session (30-45 minutes)
- Guided learning with SRL system
- Progress tracking and milestone completion
- Quiz assessments between modules

### Phase 3: Post-Assessment (10-15 minutes)
- Learning outcome evaluation
- SRL skill improvement measurement
- System usability feedback

## Data Collection Points

### Quantitative Metrics
- Time to complete modules
- Quiz scores and pass rates
- Number of help requests
- Learning plan adherence
- Progress tracking accuracy

### Qualitative Metrics
- User feedback on learning experience
- SRL strategy adoption
- System usability ratings
- Learning confidence changes

## Token Usage Projection
- **Per Participant**: ~2,000 tokens (optimized)
- **200 Participants**: 400,000 tokens total
- **Study Duration**: 2-3 days (within daily limits)
- **Buffer**: 100,000 tokens for retries/errors

## Success Criteria
- 80%+ completion rate
- Significant SRL skill improvement (pre/post)
- Positive user experience ratings
- Valid research data collection
